# NU Play Lab 웹앱

부모가 나이·공간·발달 목표·시간·피할 요소와 관심사를 입력해 오늘의 놀이
초안을 만들고 승인한 뒤, NU40-DK BLE 센서 리모컨으로 조작하는 로컬
웹앱이다.

```bash
npm install
npm run dev
```

Chrome 또는 Edge에서 `http://localhost:3000`을 연다. 부모 조건을 입력해
`게임 초안 만들기`를 누르고 내용을 확인한 뒤 `승인하고 시작`을 누른다.
마우스와 방향키/Enter는 보드 연결 없이도 작동한다. 센서 리모컨은
`Bluetooth 연결`을 누르고 `MZSZ-TOY`를 선택한다.

- IMU 좌우 기울기: 선택지 이동
- 터치 센서: 현재 선택 확인
- 조이스틱 좌우: 선택지 이동
- 조이스틱 버튼: 현재 선택 확인
- 정답 진행: NU40-DK LED0~LED3 순서대로 점등
- 생성 방식: 색·수·모양·감정의 검증된 규칙에서 로컬 생성
- 안전 흐름: 초안은 부모가 승인하기 전까지 조작 불가
- 저장 방식: 승인한 오늘의 계획을 브라우저에 로컬 저장

```bash
npm run build
npm test
```

전체 설명은 상위 폴더의 [`docs/`](../docs/README.md)를 참고한다.
