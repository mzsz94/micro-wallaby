무선 연결 상태

같은 Wi-Fi에서 연결
  1. 01 · 맥북로컬 서버 확인 중이 제어 화면과 통신을 확인합니다.
  2. 02 · NU87 Wi-Fi연결 확인 중게이트웨이 응답과 IP를 확인합니다.
  3. 03 · NU40 Bluetooth연결 확인 중화면 제어 앱의 응답을 확인합니다.

맥북과 NU87은 같은 Wi-Fi에 연결하고, NU40은 NU87과 Bluetooth로 연결합니다.

이 목록은 NU87이 수신한 BLE 광고를 보여줍니다. 맥북의 직접 BLE 검색 결과는 별도로 확인합니다.

NU87에서 검색한 뒤 보드의 이름과 주소를 선택해 주세요.
