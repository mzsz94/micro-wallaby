# 8. 실제 집 제어로 확장하기

현재 구현은 화면 속 조명과 보드 LED만 제어하는 안전한 가상 환경이다. 실제 집을
제어하려면 기능보다 먼저 안전과 보안을 설계해야 한다.

## 권장 확장 순서

1. **가상 장치 확대**: 에어컨, 커튼, 현관문을 서로 다른 상태 모델로 추가
2. **제스처 확정**: 실험 로그를 보고 기울기·흔들기·터치 규칙을 고정
3. **상태 저장**: 브라우저 `localStorage` 또는 로컬 백엔드에 저장
4. **BLE 보안**: 페어링, 암호화, 허용 장치 목록 적용
5. **게이트웨이 도입**: 맥이나 라즈베리파이가 BLE와 실제 홈 네트워크 사이 중계
6. **실제 장치 연동**: Home Assistant, Matter, MQTT 등과 연결
7. **실패 안전 설계**: 연결 끊김, 중복 명령, 센서 오동작 시 안전한 기본 상태

## 실제 제어에서 반드시 추가할 것

- 명령마다 순번과 확인 응답
- 중복 명령 방지
- 허가되지 않은 BLE 연결 차단
- 위험 장치에 대한 확인 동작
- 도어록·난방 등에는 타임아웃과 물리 스위치 우선권
- 모든 명령의 시간과 출처 기록

## 소프트웨어 구조 권장안

```text
NU40 센서 리모컨
       ↓ BLE
로컬 게이트웨이
       ↓ 인증된 API
집 상태 서비스
  ├─ 가상 웹 UI
  ├─ Home Assistant
  └─ Matter/MQTT 장치
```

웹페이지가 실제 장치를 직접 제어하게 하기보다, 검증과 인증을 담당하는 로컬
게이트웨이를 사이에 두는 편이 안전하고 여러 사용자를 지원하기 쉽다.
