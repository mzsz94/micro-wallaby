# 2. 하드웨어와 배선

## 사용 부품

- NUCODE NU40-DK / nRF52840
- `NU-IMU-LSM6DS3TR` 6축 IMU
- KY-036 계열 4핀 터치 감지 모듈
- USB 케이블: 전원, 플래시, USB CDC 디버깅

## IMU 배선

IMU는 Arduino I²C0 버스를 사용한다.

| IMU | NU40-DK | nRF52840 |
|---|---|---|
| VCC | VIO / 3.3V | 3.3V |
| GND | GND | GND |
| SDA | Arduino SDA | P0.26 |
| SCL | Arduino SCL | P0.27 |

LSM6DS3TR의 I²C 주소는 SA0 상태에 따라 `0x6A` 또는 `0x6B`가 될 수 있다.
펌웨어는 두 주소를 모두 탐색하고 `WHO_AM_I=0x6A`인지 확인한다.

## 터치 센서 배선

| 터치 센서 핀 | NU40-DK 연결 | 용도 |
|---|---|---|
| VCC 또는 `+` | VIO / 3.3V OUT, 58번 패드 | 전원 |
| GND 또는 `-` | GND, 60번 패드 | 공통 접지 |
| DO 또는 D0 | P0.02, 1번 패드 | 임계값 디지털 출력 |
| AO 또는 A0 | P0.03 / AIN1, 2번 패드 | 연속 아날로그 출력 |

아날로그 입력은 nRF SAADC 내부 0.6V 기준, 1/6 gain, 12비트로 설정했다.
따라서 약 0~3.6V 범위를 읽을 수 있다. 실제 확인에서는 평상시 약 3.29V,
터치 시 약 0.65V로 변했고 D0도 `0 → 1`로 바뀌었다.

## 보드 LED의 의미

웹의 네 방 상태를 보드 LED 네 개에 대응시켰다.

| 웹 방 번호 | 보드 LED | GPIO |
|---|---|---|
| 0 거실 | LED0 | P0.13 |
| 1 주방 | LED1 | P0.14 |
| 2 침실 | LED2 | P0.15 |
| 3 현관 | LED3 | P0.16 |

마우스나 센서로 웹 스위치를 변경하면 웹이 BLE 명령을 보드에 쓰고 해당 LED가
같이 바뀐다.

## 배선 시 주의

- 센서는 NU40-DK와 반드시 GND를 공유해야 한다.
- nRF52840 GPIO 보호를 위해 센서 전원은 3.3V를 권장한다.
- 전원이 켜진 상태에서 VCC와 GND를 바꾸지 않는다.
- IMU가 검색되지 않으면 SDA/SCL이 서로 바뀌지 않았는지 먼저 확인한다.
