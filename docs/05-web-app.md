# 5. 웹앱 구조와 제어 흐름

## 위치와 기술

- 소스: `web/`
- 주요 컴포넌트: `web/app/DailyGameLab.tsx`
- 화면: React 19 + TypeScript
- 빌드: vinext / Vite
- 로컬 주소: `http://localhost:3000`
- 저장: 브라우저 `localStorage`에 날짜별 부모 조건과 승인 상태 저장

Chrome이 Web Bluetooth로 NU40-DK에 직접 연결한다. 별도 모바일 앱이나
IDE는 필요하지 않다.

## 입력 흐름

모든 입력은 `moveSelection()`과 `submitChoice()` 두 함수로 모인다.

```text
IMU 기울기 ───┬→ moveSelection() → 선택 카드 이동
조이스틱 X ───┤
방향키 ───────┘

터치 상승 에지 ───┬→ submitChoice() → 정답 검사 → 화면 피드백
조이스틱 버튼 ────┤                          └→ BLE 명령 → 보드 LED
마우스/Enter ─────┘
```

보드 연결 없이 마우스 또는 키보드로 전체 게임을 시험할 수 있다. 실제 보드를
연결하면 첫 12개 가속도와 조이스틱 샘플을 평균 내 기준 자세와 중심값으로
사용한다.

- 기준 X축과 차이가 `+480mg` 이상: 다음 선택지
- 기준 X축과 차이가 `-480mg` 이하: 이전 선택지
- 차이가 `±220mg` 안으로 돌아오면 다음 기울기 허용
- 터치 `false → true`: 현재 선택 제출
- 터치 디바운스: 350ms
- 조이스틱 X축 중심과 차이가 `42` 이상: 이전/다음 선택지
- 조이스틱 X축 중심과 차이가 `18` 안: 다음 이동 허용
- 조이스틱 버튼 `false → true`: 현재 선택 제출, 350ms 디바운스

## 오늘의 게임 생성

`createDailyGame(prompt, date, context)`는 부모 프롬프트, 나이·공간·목표·시간과
한국 날짜를 해시하여 항상 재현 가능한 게임 명세를 만든다. 같은 날짜와 같은
조건은 같은 게임이 된다.

현재 허용한 게임 규칙은 다음 네 가지다.

1. 색깔 찾기
2. 1~4 개수 세기
3. 모양 찾기
4. 감정 표정 찾기

프롬프트의 `우주`, `동물`, `바다`, `숲`, `공룡` 같은 단어가 배경 주제를
정하고 `색`, `숫자`, `모양`, `감정` 같은 단어가 놀이 규칙을 정한다. 임의의
JavaScript를 만들거나 실행하지 않으므로 생성 결과가 검증된 게임 범위를
벗어나지 않는다.

## 게임 진행

- 한 게임은 네 라운드다.
- 오답에는 감점이나 부정적 표현 없이 다시 살펴보도록 안내한다.
- 정답마다 화면의 진행 표시가 채워진다.
- BLE가 연결돼 있으면 정답 순서대로 NU40-DK LED0~LED3을 켠다.
- 게임을 다시 만들거나 다시 시작하면 네 LED를 모두 끈다.

## 브라우저 저장

승인한 부모 조건과 승인 상태는 `nu-play-plan:YYYY-MM-DD` 키로 현재
브라우저에만 저장된다. 이전 버전 호환을 위해 `nu-play-prompt:YYYY-MM-DD`도
읽는다. 아이 이름, 사진, 음성 같은 개인정보는 수집하지 않는다. 서버나 다른
PC로 동기화되지 않는다.
