# 10. 소개 슬라이드 요구사항과 구현 범위

## 제품 흐름

소개 슬라이드의 핵심 제품 흐름을 웹앱에 다음과 같이 반영했다.

```text
부모 조건 입력 → 안전한 게임 초안 → 부모 최종 승인 → 로컬 BLE 놀이
```

부모는 아이 나이, 오늘의 공간, 발달 목표, 놀이 시간, 피할 요소와 관심사를
입력한다. 게임 초안은 부모 승인 전까지 조작할 수 없으며, 승인한 계획은 해당
날짜의 브라우저에 저장된다.

## 현재 구현된 항목

| 슬라이드의 제품 원칙 | 현재 구현 |
|---|---|
| 부모의 한 문장으로 매일 다른 놀이 | 날짜와 부모 입력을 조합해 주제와 문제를 결정 |
| 나이·공간·목표·시간 지정 | 네 가지 선택 항목을 부모 입력 화면에 제공 |
| 금지 요소와 안전 확인 | 피할 요소 입력 및 승인 전 최종 확인 |
| 부모 최종 승인 | `초안 → 부모 승인 → BLE 놀이` 3단계 잠금 흐름 |
| 외부 콘텐츠 차단 | 현재 생성기는 외부 API·광고·자동 재생을 사용하지 않음 |
| 로컬 BLE 플레이 | MZSZ-TOY와 Web Bluetooth로 직접 통신 |
| 화면을 계속 보지 않는 몸놀이 | 부모가 미션을 읽고 아이가 IMU와 터치로 응답 가능 |
| 한 기기에 여러 입력 모듈 | IMU·터치·조이스틱을 동시에 읽고 같은 게임 동작으로 통합 |
| 연령별 보호 원칙 | 0–3세 보호자 동반과 배선·케이스 점검 안내 표시 |

## 아직 프로토타입인 항목

- 현재 게임 초안은 외부 AI가 아니라 허용된 네 가지 규칙으로 로컬 생성한다.
  실제 AI 연결 시에는 모델이 실행 코드를 만들지 않고 제한된 JSON 게임 명세만
  반환하도록 서버 검증 계층이 필요하다.
- 현재 실제 입력 모듈은 IMU, 터치, 조이스틱이다. 거리·빛 센서, 압력 패드,
  RFID/NFC는 하드웨어·펌웨어·BLE 패킷 확장 후 사용할 수 있다.
- 나이 선택은 제품 흐름에 반영했지만, 영아용 게임 규칙은 별도의 발달·안전
  검토 전까지 보호자 진행 프로토타입으로만 사용한다.
- 웹앱은 외부 인터넷 API를 호출하지 않지만, 개발 서버 자체를 끈 뒤에도 다시
  열리는 설치형 오프라인 앱(PWA)은 아직 아니다.

## 구현 원칙

소개 슬라이드의 연구·시장 문구는 제품 방향 자료로 취급한다. 실제 연령별 놀이
가이드나 효과를 제품에 확정 적용하기 전에는 원문 연구와 전문가 검토가 별도로
필요하다. 이 앱은 발달 지원 놀이 도구이며 진단이나 치료 도구가 아니다.
