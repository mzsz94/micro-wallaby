## 현재 완성된 기능

- NU40-DK에서 LSM6DS3TR 가속도·자이로 6축 읽기
- KY-036 계열 터치 센서의 디지털·아날로그 입력 읽기
- USB CDC 터미널 실시간 출력
- 커스텀 BLE GATT 서비스 광고 및 10 Hz 센서 알림
- IMU와 조이스틱 좌우 입력으로 게임 선택지 이동
- 터치 상승 에지와 조이스틱 버튼으로 현재 답 제출
- 게임 정답 진행을 NU40-DK LED0~LED3에 BLE 명령으로 반영
- IMU 자동 기준 자세 보정과 최근 동작 로그
- 부모 프롬프트와 날짜로 색·수·모양·감정 게임 생성
- 나이·공간·발달 목표·놀이 시간·금지 요소를 반영한 게임 초안
- 부모 최종 승인 후에만 입력을 받는 3단계 놀이 흐름
- 승인한 오늘의 놀이를 브라우저에 로컬 저장
- IMU로 선택지를 이동하고 터치로 답을 확인하는 오늘의 게임 화면
- 마우스·방향키·Enter를 이용한 보드 없는 시험
- BLE 연결 해제 후 광고 자동 재시작과 RESET 없는 재연결

이 프로젝트는 **로컬 가상 시뮬레이션**이다. 실제 가전이나 도어록을 제어하기
전에는 인증, 암호화, 오작동 방지 설계가 추가로 필요하다.
