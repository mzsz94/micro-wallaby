# 9. 오늘의 성장 놀이 프로젝트

## 목표

부모가 아이 나이, 놀이 공간, 발달 목표, 놀이 시간, 피할 요소와 관심사를
입력하면 그날의 짧은 게임 초안을 만든다. 부모가 내용을 확인하고 승인한 뒤
아이가 NU40-DK 센서 리모컨으로 플레이한다.

이 앱은 발달을 지원하는 가족 놀이이며 발달 수준을 진단하거나 치료 효과를
판정하는 도구가 아니다.

## 부모와 아이의 화면 역할

부모 영역에서는 구조화된 조건과 관심사 문장을 입력한다. `게임 초안 만들기`
버튼을 누르면 오른쪽에 네 문제로 구성된 초안이 나타난다. 초안 상태에서는
선택지가 잠겨 있고, 부모가 나이·공간·시간·목표·피할 요소를 다시 확인한 뒤
`승인하고 시작`을 눌러야 놀이 입력이 활성화된다.

아이 영역은 글자를 읽지 못해도 부모와 함께 사용할 수 있도록 큰 선택 카드,
이모지, 색상, 짧은 문장으로 구성했다. 웹은 보호자 진행 화면으로 사용할 수
있으며, 부모가 미션을 읽어주면 아이는 화면을 계속 보지 않고 보드를 움직이고
터치할 수 있다.

## 부모 입력과 승인 흐름

1. `아이 나이`, `오늘의 공간`, `발달 목표`, `놀이 시간`을 선택한다.
2. 큰 소리, 점프, 작은 부품처럼 피할 요소를 적는다.
3. 아이 관심사를 한 문장으로 적고 `게임 초안 만들기`를 누른다.
4. 부모가 생성된 놀이 조건과 문제를 검토한다.
5. `승인하고 시작`을 눌러 입력을 활성화한다.
6. 승인한 계획은 해당 날짜의 브라우저 로컬 저장소에 보관된다.

## 현재 입력 장치

| 입력 | 게임 동작 |
|---|---|
| IMU 좌우 기울기 | 이전/다음 선택지 이동 |
| 터치 센서 | 현재 선택 제출 |
| 조이스틱 X축 | 이전/다음 선택지 이동 |
| 조이스틱 버튼 | 현재 선택 제출 |
| 마우스 | 카드 선택 및 제출 |
| 방향키 좌/우 | 이전/다음 선택지 이동 |
| Enter 또는 Space | 현재 선택 제출 |

아날로그 조이스틱 X/Y와 버튼은 BLE 버전 2 패킷으로 전송한다. 현재 게임에서는
X축을 선택지 이동, 버튼을 제출에 사용한다. Y축 값도 웹에 표시되어 이후 상하
이동 게임에 사용할 수 있다. 기존 터치와 IMU 입력도 동시에 작동한다.

## 로컬 생성과 향후 AI 생성

현재 버전은 외부 API 없이 동작하는 안전한 로컬 생성기다. 장점은 인터넷이나
API 키가 없어도 작동하고, 게임 규칙이 예측 가능한 네 종류로 제한된다는 점이다.

향후 언어 모델을 연결하더라도 모델이 웹 코드를 직접 생성해서 실행하게 하지
않는다. 모델은 제목, 안내 문장, 주제, 난이도 같은 JSON 게임 명세만 반환하고
서버가 허용 목록과 범위를 검사한 뒤 기존 게임 엔진에 전달해야 한다. API 키는
브라우저가 아니라 로컬 서버 환경변수에 저장해야 한다.

## 실행 순서

```bash
make web-install
make web-dev
```

1. Chrome 또는 Edge에서 `http://localhost:3000`을 연다.
2. 나이·공간·목표·시간·피할 요소와 관심사를 입력한다.
3. `게임 초안 만들기`를 누르고 내용을 검토한다.
4. `승인하고 시작`을 누른다.
5. 마우스나 키보드로 게임이 정상 동작하는지 확인한다.
6. `Bluetooth 연결`을 누르고 `MZSZ-TOY`를 선택한다.
7. 보드를 잠시 고정해 자동 보정을 마친다.
8. IMU를 좌우로 기울이고 터치 센서로 답을 제출한다.

## 다음 하드웨어 단계

현재 조이스틱 연결은 다음과 같다.

| 조이스틱 | NU40-DK |
|---|---|
| VCC | 3.3V |
| GND | GND |
| VRX | P0.04 / AIN2 |
| VRY | P0.28 / AIN4 |
| SW | P1.03 / D2 |

조이스틱을 5V에 연결하지 않는다. 터치·IMU·조이스틱은 3.3V와 GND를 공유한다.
