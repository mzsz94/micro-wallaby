# 7. 문제 해결

## `NRF52BOOT`가 보이지 않는다

- RESET을 느리게 누르면 일반 재부팅만 된다. 빠르게 두 번 누른다.
- 안 되면 BUTTON0을 누른 상태로 USB를 다시 연결해 본다.
- `make detect`로 부트로더 정보를 확인한다.

## macOS의 “디스크가 제대로 추출되지 않음” 알림

UF2 복사가 끝나자마자 보드가 자동 재부팅하며 가상 디스크를 해제하기 때문이다.
보드가 Zephyr USB 장치로 다시 나타나고 새 펌웨어가 실행되면 정상이다. 맥 내부
디스크에는 영향이 없다.

## USB 터미널에 아무것도 나오지 않는다

```bash
ls /dev/cu.usbmodem*
make monitor
```

모니터를 연 뒤 RESET을 한 번 누르면 부팅 메시지부터 볼 수 있다. 다른 터미널
프로그램이 같은 포트를 열고 있으면 먼저 닫는다.

## 웹에서 Bluetooth 버튼을 눌러도 장치 창이 안 뜬다

- Safari 대신 Chrome 또는 Edge를 사용한다.
- 주소가 `http://localhost:3000`인지 확인한다.
- macOS 설정의 개인정보 보호 및 보안에서 Chrome의 Bluetooth 권한을 확인한다.
- 장치 창은 페이지 자동 실행이 아니라 버튼 클릭으로만 열 수 있다.

## 목록에 `MZSZ-TOY`가 없다

- 보드에 BLE 버전 펌웨어가 플래시됐는지 확인한다.
- USB 전원이 들어와 있는지 확인한다.
- 다른 브라우저나 앱이 이미 연결 중이면 연결을 끊는다.
- `make monitor`에서 `BLE advertising: MZSZ-TOY`를 확인한다.

## 연결 직후 끊긴다

- 웹페이지를 새로고침한 뒤 다시 연결한다.
- 보드와 맥의 거리를 줄인다.
- USB 전원과 센서 배선을 확인한다.
- Chrome 장치 권한에서 기존 항목을 지우고 다시 선택해 본다.

## IMU 값이 모두 0이거나 unavailable이다

- SDA=P0.26, SCL=P0.27 배선을 확인한다.
- VCC=3.3V, GND 공통 여부를 확인한다.
- USB 로그의 I²C scan에 `0x6a` 또는 `0x6b`가 있는지 확인한다.
- `WHO_AM_I(0x0f)=0x6a`가 나와야 LSM6DS3TR로 인식된다.

## 기울기 방향이 반대이거나 선택이 너무 민감하다

- 웹의 `기준 자세 다시 보정`을 누르고 평소 자세로 고정한다.
- `HomeLab.tsx`에서 480mg 선택 임계값을 키우면 덜 민감해진다.
- 220mg 해제 임계값을 너무 높이면 다음 기울기를 받기 어려워진다.
- 장착 방향에 따라 `deltaX` 대신 `deltaY`를 사용한다.

## 터치가 계속 켜져 있거나 전환되지 않는다

- 센서 가변저항으로 D0 임계값을 조절한다.
- 웹에서 mV 값이 변하는지 먼저 확인한다.
- D0=P0.02, A0=P0.03 연결이 바뀌지 않았는지 확인한다.

## 웹 빌드가 실패한다

```bash
cd web
npm install
npm run build
```

Node.js는 22.13 이상이 필요하며 현재 환경에는 Node.js 24가 설치돼 있다.
